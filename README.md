# POISA BORBAAD — Luxury Online Casino & Private Salon

An interactive, minimalist luxury online casino web application built with React 19, TypeScript, Vite, Tailwind CSS v4, and Google OAuth.

- **Crown 777 Slots**: Multi-line tumbling reel slot machine with payline win-paths and jackpot fanfare.
- **European Roulette**: 37-pocket interactive felt with hover zone highlights, elastic chip placement, and decelerating wheel physics.

- **Minimalist Luxury Aesthetic**: Monte Carlo private salon theme with obsidian tones, champagne gold accents, and subtle ambient glows.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/thecybertronkid/casinoroyale.git
cd casinoroyale

# Install dependencies
npm install

# Run the development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
